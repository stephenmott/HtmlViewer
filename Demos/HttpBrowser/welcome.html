border-radius (new)

Order summary – rounded box, 2px solid border (the real use case).

Corner-alignment matrix – the border should hug the rounded background at every width, and the filled box's corners should be clean:

radius 8px · border 1px
radius 8px · border 3px
radius 8px · border 6px (thick – best test for the inset math)
radius 20px · border 2px
radius 28px · border 2px (pill)
radius 12px · no border (filled)

outline (new)

A solid outline looks like a border on its own – the point is it sits outside the border and, with outline-offset, leaves a gap. These boxes have a grey border AND a coloured outline:

grey border + red outline, 7px gap (outline-offset)
grey border + blue outline, 5px gap, rounded

Custom properties – var() (new)

var(--brand) – this line uses the brand colour defined on :root.

var(--accent) – the accent colour.

var(--missing, #4a8f4a) – the variable is undefined, so the green fallback is used.

This card's padding and corner radius come from var(--pad) and var(--radius).

calc() (new)

width: calc(100% - 80px) – always 80px narrower than the card, at any window size.
width: calc(50% - 10px)

The card's padding above also mixes a variable and a literal: calc(var(--pad) + 6px).

rem units (new)

1rem · 1.5rem · 2rem

rem is relative to the document's root font size.

@media width queries (new)

Resize the window and watch this box change as it crosses a breakpoint: green when wider than 1000px, amber between 700 and 1000px, red at 700px or narrower. (It re-evaluates the @media rules on resize.)
